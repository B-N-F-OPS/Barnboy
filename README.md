## Dashboard Project
## Overview

This project is a responsive dashboard that helps hatcheries monitor Batches, sales and expenses

## Features

* 📱 Responsive design for desktop and tablet
* 🎨 Clean and user-friendly interface
* ⚡ Fast and efficient dashboard experience
* 🧩 Reusable dashboard components

## Tech Stack

* **Frontend:** [Next.js]
* **Styling:** [Tailwind CSS]
* **Backend:** [next.js]
* **Database:** [supabase]
* **Authentication:** [Clerk]


## Getting Started

### Prerequisites

Make sure you have the required development environment installed, such as Node.js and npm.

### Installation

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd Barnboy
npm install
```

### Running the Project

Start the development server:

```bash
npm run dev
```

Then open the local development URL shown in your terminal.
